Real example flows

Flow A · free kudos

Syed recognizes Shourya

1Syed opens the portal, taps Give kudos, picks Shourya, writes: “Rebuilt the test cases the night before the module demo.”
2AI agent check: names a real contribution, clean tone, recipient exists in the directory.
3Posted to the feed — no points, no cost. Badge on Shourya's profile.
4The tree resolves Shourya's manager → Prateesh is notified on his dashboard.
Every kudos is free. Recognition and money are two different things by design.
Flow B · kudos with points

Syed adds +50 to Shourya

1Same kudos flow, but Syed taps Attach a reward and picks +50.
2Peer cap enforced by the system: max 100 points per kudos.
3Shourya's wallet ledger shows +50 with the reason and date.
4Prateesh sees it aggregated in the manager dashboard (+ points, category, trends).
Flow C · manager boost

Prateesh gives Nikhilesh +500

1Prateesh opens the manager dashboard and boosts Nikhilesh's withdrawn-pipeline fix with +500.
2Budget guardrail: team wallet is 10,000/month; 6,500 used → this lands fine at 7,000.
3If he tried 5,000 → blocked: “Budget limit exceeded — 3,500 remaining”, with two buttons: reduce amount or request more budget (goes to Prastina).
4Nikhilesh gets notification + ledger entry.
Flow D · Employee of the Quarter

Prateesh nominates Nikhilesh

1Prateesh nominates Nikhilesh for Q3 Excellence — justification: rebuilt the failing test suite overnight, zero post-launch bugs.
2AI review: eligibility ✓ evidence from recognition history ✓ no duplicate ✓ policy ✓ — and drafts an AI summary for the jury.
3Approval chain from the tree: Prastina (senior manager) → Shan (org head) → HR/awards committee.
4Peers can endorse the same nomination instead of duplicating it.
5Jury sees all files and votes. Winner gets +5,000 points straight into the wallet → redeemed in the marketplace as vouchers.
Variant: if an intern (say Syed) nominates instead, approval starts at Prateesh, then Prastina → Shan. The tree, not the person, decides the route.

The 7 personas, mapped on the real tree

1Employee — Nikhilesh: receives awards, earns and spends points.
2Peer Employee — Syed (any other intern): peer kudos, attaches rewards up to the 100-pt cap.
3Manager L1 — Prateesh: manager of three, budget owner; carries the Manager boost quota (10,000/mo).
4Manager L2 — Prastina: senior-manager approvals; would carry a Quarterly Excellence quota.
5Manager L3 — Shan: org head; would carry the Annual Pride quota.
6Manager with Quota & Budget — not one fixed person: each award type names its own carrier (boost → Prateesh, quarterly → Prastina, annual → Shan, EoQ → the awards office). Admin/HR can change it in the Award rules screen.
7Admin / HR — the awards office: rules, buckets, ballot clearance, jury. No individual named here on purpose.
Key rule: the quota-carrying manager changes per award type — the registry (Award rules) decides, not the org chart alone.
